This is a JavaScript library (`superformdata`) for serializing rich JavaScript values (objects, arrays, `Date`, `Set`, `Map`, `bigint`, `RegExp`, `URL`, `Error`, and special numbers) into form-style `[string, string][]` entries and decoding them back again — useful for moving typed data through `FormData`, URL-encoded forms, or HTTP request bodies.
This project uses Bun as the package manager. NEVER use `npm` or `yarn` to install dependencies or run scripts.
